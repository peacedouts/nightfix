The Nightfix agent is starting ({{ .Values.replicaCount }} replicas). It enrolls by proving its IAM role, so
the control plane needs an enrollment rule for that role:

  curl -X POST <api>/v1/enrollment-rules -H "Authorization: Bearer $NIGHTFIX_API_KEY" \
    -d '{"method": "iam", "role_arn": "<role ARN of the service account>", "labels": {"env": "prod"}, "max_agents": {{ mul .Values.replicaCount 2 }}}'

Then check: curl <api>/v1/agents -H "Authorization: Bearer $NIGHTFIX_API_KEY"
